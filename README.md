# Gilded Growth

Navrhni prémiový, matně luxusní design pro one-page web studentských marketingových služeb (weby + propagace pro menší projekty a firmy). BAREVNÁ PALETA (dodržet přesně, žádné jasné/lesklé odstíny): - Pozadí: matná antracitová černá #141210 - Sekundární plochy (karty): #1E1B18 - Akcent: matné staré zlato #C9A24B - použít úsporně (linky, nadpisy, ikony, rámečky), NIKDY jako velkou vyplněnou plochu ani jako lesklý gradient - Hlavní text: teplá slonová kost #F5F0E6 - Sekundární text: tlumená šedohnědá #8A8378 TYPOGRAFIE: - Nadpisy (hero, čísla v ceníku): elegantní serif s výrazným kontrastem tahů (Playfair Display nebo Fraunces) - Běžný text: čistý moderní sans (Inter nebo Manrope) - Labely sekcí (např. "SLUŽBY", "PORTFOLIO"): malé, prostrkané kapitálky, tenký řez, zlatá barva STYL A DETAILY: - Matný, nikoli lesklý vzhled - žádné třpytivé gradienty ani glow efekty - Tenké 1px zlaté dělící linky mezi sekcemi místo výrazných boxů/stínů - Karty služeb a portfolia s jemným zlatým rámečkem (nízká opacita), ploché pozadí, bez ostrých stínů - Hodně černého prostoru - zlatá je akcent, ne dominance - Jemná animace: při načtení stránky se pod hero nadpisem "vykreslí" tenká zlatá linka zleva doprava SEKCE: Hero s CTA "Domluvit konzultaci", O mně, Služby (karty), Portfolio (grid), Ceník (tabulka se 3 balíčky, orientační ceny), Kontaktní formulář (jméno, e-mail, popis projektu, rozpočet). TÓN: profesionální, dospělý, důvěryhodný - cílí na majitele malých firem a projektů, ne na vrstevníky. Responzivní pro mobil, čitelný kontrast textu na tmavém pozadí.
